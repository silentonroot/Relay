# Acceptance Test Matrix

This file lists every acceptance scenario with a stable ID. The Status column is updated only from tests that exist. Evidence names the test file and test.

In Evidence, `W:` stands for `services/browser-worker/test/`, `A:` for `services/broker-api/test/` and `D:` for `packages/database/test/`.

On 2026-11-13 type checking, ESLint and Prettier were clean, and the package test suites passed in the project lead's runs: contracts 57, crypto 120, audit 182, policy-engine 197, adapter-sdk 160, adapters/northstar 88, database 118 on the in-process database (119 on PostgreSQL 18, which adds the concurrent job-claim test), broker-api 124, dashboard 101 and browser-worker 231, which is 1,378 tests across those packages (the PostgreSQL-only test and the 15 end-to-end steps are not in that sum). With a Docker engine and the runner image present, browser-worker has 236 tests (the five in `W:integration/docker.test.ts`) and the total is 1,383. The end-to-end test (`AAB_E2E=1`, `W:e2e/phase2.e2e.test.ts`, about 85 seconds) passed three consecutive times. The sandbox integration tests need bubblewrap and Chromium (the login test also Xvfb, xdotool and xauth) and skip when they are missing; the end-to-end test needs those plus PostgreSQL and runs only with `AAB_E2E=1`; continuous integration runs neither, and it does not run the Docker tests, build the images or start the Compose stack. The images and the Compose stack were checked by hand on 2026-11-13 (threat model section 6.1); no scenario in this matrix rests on that check. One browser-worker test, `W:integration/login.test.ts` "the owner signs in; complete() returns the session cookie and account hint", failed once in a documentation-review run at a runtime-directory listing comparison and passed when run alone.

Allowed Status values:

- **Planned**: no test yet, or only a test that proves part of the scenario. Evidence says which.
- **Implemented (unverified)**: a test exists but the lead has not confirmed a passing run.
- **Verified**: the lead confirmed a passing run.
